# Festival de Degustação Japonesa

Projeto desenvolvido para a disciplina de Desenvolvimento Web I do Instituto Federal de São Paulo (IFSP).

## Descrição
Página web estática criada com HTML5 e CSS3 para divulgar um evento fictício de gastronomia e cultura japonesa.

## Tecnologias
- HTML5
- CSS3

## Funcionalidades
- Menu de navegação
- Informações sobre o evento
- Programação
- Cardápio
- Galeria de imagens
- Local do evento
- Vídeo
- Contato
- Layout responsivo
